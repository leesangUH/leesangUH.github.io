HOW TO PUBLISH THIS SITE AT https://leesang.github.io/

1. Sign in to GitHub and open the repository named: leesang.github.io
2. Click "Add file" > "Upload files".
3. Upload the CONTENTS of this folder (not the folder itself):
     index.html
     cv2.pdf
     assets/   (including profile.jpg)
4. Click "Commit changes".
5. Wait a minute or two, then visit https://leesang.github.io/

If the site does not appear:
- Open the repository's Settings > Pages.
- Under "Build and deployment", choose "Deploy from a branch".
- Select branch "main" and folder "/ (root)", then Save.

Important: index.html must be in the repository's top/root level.
